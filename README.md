# Fluid Dynamics
This repository contains a Jupyter notebook for analyzing quantities in a fluid dynamics system, particularly for Nitrogen gas flowed through tubes of varying sizes. 

Impedances, flow rates, and pressure differentials are some analyzed quantities.

This analysis is primarily carried out in relation to the Radon Purge System, where the SuperCDMS Radon Barrier pressure differential has to be carefully managed by a flow controller and check valves.
